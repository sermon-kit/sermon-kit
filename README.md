# Sermon Kit Free v8

무료 범위에서 동작하도록 구성한 설교 쇼츠 제작 웹앱입니다.

## 포함 기능

- 공개 YouTube 설교를 Gemini로 분석
- 30초 / 1분 / 3분 쇼츠 후보 5개 추천
- 선택 구간 YouTube 미리보기
- 제목 5개 / 설명 / 해시태그 / 썸네일·첫 화면 문구 생성
- 선택 구간 자막 자동 생성
- **자막 편집기**
  - 자막 문장 직접 수정
  - 시작/종료 시간 수정
  - 자막 추가/삭제
  - 시간순 정리
  - 편집된 SRT 다운로드
- Gemini TTS AI 음성 생성 및 WAV 다운로드
- 편집 자막을 AI 음성 원고에 바로 반영
- **브라우저에서 9:16 MP4 제작 및 다운로드**
  - 원본 MP4 사용
  - 원본 유지 + 흐린 배경 / 화면 꽉 채우기
  - 원본 음성 / 생성한 AI 음성 선택
  - 720×1280 / 1080×1920 선택
  - 편집한 자막을 영상에 직접 삽입
  - 첫 3초 후킹 문구 삽입

## 무료 MP4 제작 방식

MP4 렌더링은 별도 서버를 사용하지 않고 `ffmpeg.wasm`을 사용해 **사용자의 브라우저 안에서 직접 처리**합니다.

따라서 별도 영상 렌더 서버 비용은 들지 않습니다. 다만 브라우저의 메모리와 CPU를 사용하므로 긴 원본 영상이나 1080p 렌더링은 시간이 오래 걸릴 수 있습니다. 720×1280을 기본 추천합니다.

원본 MP4는 서버에 업로드되지 않습니다.

## 무료판에서 제외한 기능

- AI 이미지 자동 생성
- 타인의 YouTube 영상을 자동 다운로드하는 기능
- 서버 기반 대용량 영상 렌더링
- 음성 복제

## GitHub에 올리는 방법

1. 이 ZIP 파일의 압축을 풉니다.
2. GitHub의 기존 `sermon-kit/sermon-kit` 저장소로 이동합니다.
3. `Add file` → `Upload files`를 누릅니다.
4. **압축 푼 폴더 안의 파일과 폴더 전체**를 업로드합니다.
5. `Commit changes`를 누릅니다.
6. 기존 Vercel 프로젝트가 GitHub 저장소와 연결되어 있다면 자동으로 다시 배포됩니다.

## 사용 순서

1. Gemini API 키 입력
2. 공개 설교 YouTube 주소 입력
3. 쇼츠 길이 선택
4. 쇼츠 후보 5개 찾기
5. 후보 선택
6. 자막 만들기
7. 자막 편집
8. 필요하면 AI 음성 생성
9. 본인이 사용 권한을 가진 원본 MP4 선택
10. 화면 방식 / 음성 / 해상도 선택
11. `9:16 자막 쇼츠 MP4 만들기`
12. 렌더가 끝나면 MP4가 자동 다운로드됩니다.

## 참고

첫 MP4 렌더링 때 브라우저가 FFmpeg WebAssembly 엔진을 내려받기 때문에 시간이 조금 걸립니다. 이후 렌더링은 브라우저에서 진행됩니다.

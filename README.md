# Sermon Kit Free v9

무료 범위 중심의 설교 쇼츠 제작 웹앱입니다.

## v9 핵심 기능

- 공개 YouTube 설교 영상 Gemini 분석
- 30초 / 1분 / 3분 후보 5개
- `메시지 균형형` / `조회수·시청 유지 우선` 후보 선정
- 후보별 후킹 / 메시지 / 조회 가능성 점수
- 원문을 그대로 잘라 쓰는 방식 외에 **조회수형 쇼츠 대본 재구성**
- 재구성 대본을 자막 조각으로 자동 배치
- 기본 Gemini TTS 음성
- **본인 음성 10~30초 + 동의 음성으로 내 목소리 복제**
- 복제 음성으로 재구성 대본 읽기
- 자막 직접 편집 / 시간 조정 / SRT 다운로드
- 브라우저 FFmpeg 9:16 렌더링
- 완성 MP4 미리보기
- **별도 `완성 MP4 다운로드` 버튼**

## 내 목소리 기능

Gemini 3.8 TTS의 음성 복제 기능을 사용합니다. 앱은 `store:false` 상태 비저장 방식을 사용해 음성 프로필을 영구 저장하지 않고, 반환되는 `voicekey_...`를 사용자 브라우저 localStorage에 저장합니다. Google 문서상 상태 비저장 키의 TTL은 7일입니다.

필수 동의 문구:

> 나는 이 음성의 소유자이며 구글이 이 음성을 사용하여 음성 합성 모델을 생성할 것을 허용합니다.

반드시 본인의 음성 또는 명시적으로 허가받은 음성만 사용하세요.

## 무료판에서 제외한 기능

- AI 이미지 자동 생성
- YouTube 원본 영상 자동 다운로드
- 서버 FFmpeg 렌더링

최종 MP4 제작에는 사용 권한이 있는 원본 MP4 파일을 사용자가 선택해야 합니다. 파일은 앱 서버로 업로드하지 않고 브라우저 FFmpeg에서 처리합니다.

## GitHub / Vercel 업데이트

1. 이 ZIP을 다운로드합니다.
2. 압축을 풉니다.
3. GitHub의 기존 `sermon-kit/sermon-kit` 저장소로 이동합니다.
4. `Add file` → `Upload files`를 누릅니다.
5. ZIP 자체가 아니라 **압축을 푼 폴더 안의 파일과 폴더 전체**를 업로드합니다.
6. `Commit changes`를 누릅니다.
7. Vercel이 자동 재배포할 때까지 기다립니다.

## 참고

- API 키는 브라우저 localStorage에 저장됩니다.
- YouTube 분석은 공개 영상 기준입니다.
- 무료 등급 사용 가능 여부와 한도는 Google 정책에 따라 변경될 수 있습니다.
- 내 목소리 복제는 마이크 권한과 HTTPS 환경이 필요합니다. Vercel 배포 주소에서는 HTTPS가 기본 제공됩니다.
